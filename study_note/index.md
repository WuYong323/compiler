## 0. 一句话总览

编译原理研究的是"**如何把一种语言翻译成另一种语言，并保证翻译前后语义不变**"。这门课你会亲手写一个编译 **Cool**（一个教学用的面向对象语言）到 **LLVM IR** 的完整编译器，途经词法分析 → 语法分析 → 语义分析 → 中间表示 → 代码生成，最后理解优化、寄存器分配、垃圾回收，再抬头看 LLVM/MLIR/TVM 这些真实工业编译器在干什么。

## 1. 编译管线全图（先建立全局观）

```
Cool 源码 (.cl)
      │
      ▼
┌───────────────────────────── 前端 (Front-End) ─────────────────────────────┐
│  ① 词法分析 (Lexing)      源码字符流 → Token 流                              │
│  ② 语法分析 (Parsing)      Token 流 → 抽象语法树 AST                         │
│  ③ 语义分析 (Semantic)     AST → 带类型的 AST（符号表 + 类型检查）            │
└────────────────────────────────────────────────────────────────────────────┘
      │
      ▼
┌───────────────────────────── 中端 (Middle-End) ────────────────────────────┐
│  ④ 中间表示 (IR)           带类型 AST → 三地址码 / SSA（这里是 LLVM IR）      │
│  ⑤ 分析与优化 (Optimize)   数据流分析、常量传播、死代码消除……                 │
└────────────────────────────────────────────────────────────────────────────┘
      │
      ▼
┌───────────────────────────── 后端 (Back-End) ──────────────────────────────┐
│  ⑥ 代码生成 (Codegen)       IR → 目标代码（LLVM IR → 可执行文件）             │
│  ⑦ 寄存器分配 (RegAlloc)    图着色 / 线性扫描                                 │
│  ⑧ 运行时 (Runtime)         栈帧布局、对象布局、分发表、垃圾回收               │
└────────────────────────────────────────────────────────────────────────────┘
```

**直觉类比**：编译器和"外语翻译"是同构的——
- 词法分析 = 把句子切成一个个**词**（识别出"我/爱/编译/原理"，去掉空格标点）；
- 语法分析 = 分析**句子成分**（主谓宾，画出语法树）；
- 语义分析 = 检查**有没有歧义/病句**（"我爱"后面没宾语 → 报错；"整数加字符串" → 类型错误）；
- 代码生成 = 把中文句子**翻译成英文**（还要保证意思不变）。

## 3. 代码项目地图（`projects/coolc/`）

```
projects/coolc/
├── src/
│   ├── token.h            # Token 类型与关键字定义（02）
│   ├── lexer.h / lexer.cpp# 词法分析器：源码 → Token 流（02）
│   ├── ast.h              # 抽象语法树节点定义（03）
│   ├── parser.h / parser.cpp # 递归下降语法分析器（03）
│   ├── symtab.h           # 符号表 / 类型环境（05）
│   ├── typechecker.h / typechecker.cpp # 语义分析 + 类型检查（06）
│   ├── codegen.h / codegen.cpp # 代码生成：AST → LLVM IR 文本（09）
│   └── main.cpp           # 入口：串联整个管线（09）
├── tests/                 # Cool 测试程序（01 起陆续加入）
│   └── *.cl
├── build.bat              # Windows 一键编译（g++）
└── README.md              # 构建/运行/LLVM 安装说明
```

**构建命令**（Windows + MSYS2 g++，无需 cmake）：
```bat
cd projects\coolc
build.bat
```
等价于：`g++ -std=c++17 -Wall -o coolc.exe src\*.cpp`

**运行**：`coolc.exe tests\hello.cl` → 输出 `hello.ll`（LLVM IR 文本）。
**执行 IR**（需装 LLVM）：`lli hello.ll` 或 `clang hello.ll -o hello.exe && hello.exe`。

## 4. 学习路线与检查点（Checkpoints）

每个检查点都有**可运行的里程碑**，做完才进入下一阶段：

1. **CP1（02 末）**：`lexer` 能把 `.cl` 文件切成正确的 Token 流并打印出来（含错误报告）。
2. **CP2（03 末）**：`parser` 能把 Token 流建成 AST 并 pretty-print 回 Cool 代码。
3. **CP3（06 末）**：`typechecker` 能对合法程序报"OK"、对类型错误给出准确位置。
4. **CP4（09 末）**：`codegen` 能把带类型 AST 变成 LLVM IR，`lli` 跑出正确结果——**完整编译器完成**。
5. **CP5（14 末）**：理解优化/寄存器分配/GC 的原理，能讲清 LLVM/TVM/MLIR 的架构，形成自己的 PL 知识图谱。

| 工具 | 用途 | 现状 | 安装命令 |

| g++ (15.2) | 编译我们的编译器 | ✅ 已装 | — |
